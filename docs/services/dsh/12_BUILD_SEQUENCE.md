# 12_BUILD_SEQUENCE

## Sequence

1. stabilize handoff and target paths in `W00_FOUNDATION`
2. build the four core client entry and checkout screens in `W01_CLIENT_ENTRY_AND_CHECKOUT`
3. open visibility and partner entry in `W02_ORDER_VISIBILITY_AND_PARTNER_ENTRY`
4. open store-repair and captain execution in `W03_STORE_AND_CAPTAIN_EXECUTION`
5. open proxy and governance screens in `W04_GOVERNANCE_AND_PROXY`
6. open field support only if the branch remains justified in `W05_FIELD_SUPPORT_OPTIONAL`
7. open binding and contract targets in `W08_BINDING_AND_CONTRACT`
8. open runtime class and proof plan in `W09_RUNTIME_AND_PROOF`

## Build Stops

- stop if a wave has unresolved blockers from the prior wave
- stop if UI-Kit prerequisites are still marked missing
- stop if a screen lacks its own screen contract file
