# تشريح بصري — واجهة الأرباح وواجهة الإعدادات

## 1. واجهة الأرباح والإحصائيات

### الهيكل الحالي
| العنصر | الوصف | الملاحظات |
|--------|--------|-----------|
| **الهيدر** | عنوان "الأرباح والإحصائيات" + نوع الخدمة + آخر تحديث | ✅ واضح |
| **ملخص الأرباح** | بطاقة واحدة تحتوي شبكة 2×2 (إجمالي، الشهر، اليوم، في الانتظار) | ❌ القيم تُقطَّع (18.2k...، 165.00...) |
| **الإحصائيات وتقييمك** | بطاقة: عدد الرحلات، التقييم، هذا الأسبوع | ✅ مقبول |
| **سحب الأرباح** | زر CTA | ✅ |
| **الأرباح + المحفظة** | بطاقتان جنباً إلى جنب | ✅ |
| **المزيد** | قائمة في بطاقة واحدة | ✅ |
| **المعاملات الأخيرة** | قائمة معاملات | ✅ |

### أخطاء تم تحديدها
1. **تقليم النص (Truncation):** استخدام `numberOfLines={1}` مع عرض خلية ~50% يقطع القيم (مثل "18.2k SAR" → "18.2k..."). غير مقبول.
2. **اتساق التسميات:** الصفان السفليان (اليوم، في الانتظار) يجب أن يظهرا بوضوح مثل الصفين العلويين.
3. **عرض المحتوى:** المحتوى يستخدم `paddingHorizontal: lg` — يمكن تقليله إلى `md` لتمديد العرض ومطابقة واجهة الدعم.

### إجراءات الإصلاح (مُنفَّذة)
- إزالة `numberOfLines={1}` من قيم الملخص لتفادي القطع.
- استخدام صيغة "18.2 ألف SAR" بدلاً من "18.2k SAR" وخط 15px لضمان وضوح القيم.
- ضبط الخلايا بعرض ثابت `width: '50%'` لشبكة 2×2 مستقرة مع padding داخلي.
- توحيد هوامش المحتوى: `paddingHorizontal: BTHWANI_SPACING.md` لتمديد العرض ومطابقة الدعم.

## 2. واجهة الإعدادات

### الهيكل الحالي
| العنصر | الوصف | الملاحظات |
|--------|--------|-----------|
| **الهيدر** | "الإعدادات" + "تخصيص تجربتك في التطبيق" | ✅ |
| **التفضيلات** | بطاقة واحدة: إشعارات، تتبع الموقع، قبول تلقائي، وضع ليلي، مؤثرات صوتية | ✅ منظم |
| **الحساب والمساعدة** | بطاقة واحدة: كلمة المرور، الخصوصية، الدعم، تسجيل الخروج | ✅ |
| **معلومات التطبيق** | إصدار + حقوق النشر | ✅ |

### أخطاء تم تحديدها
1. **محتوى مضغوط في المنتصف:** استخدام `paddingHorizontal: lg` يعطي انطباع عمود ضيق ومساحات بيضاء كبيرة على الجانبين. واجهة الدعم تستخدم `padding: md` للقائمة فتبدو أوسع.
2. **الاتساق مع الدعم:** توحيد الهوامش مع واجهة الدعم والمساعدة يقلل الشعور بعدم التنظيم.

### إجراءات الإصلاح (مُنفَّذة)
- تقليل هامش الأفقي إلى `BTHWANI_SPACING.md` للأقسام ومعلومات التطبيق لتمديد البطاقات.
- البطاقات تمتد بعرض كامل داخل منطقة المحتوى.

## 3. مرجع سريع — واجهة الدعم والمساعدة (المطلوب محاكاته)

- **الحاوية:** `padding: BTHWANI_SPACING.md` لقائمة العناصر.
- **كل عنصر:** بطاقة منفصلة (padding lg، border، shadow خفيف)، عرض كامل داخل الحاوية.
- **الهيدر:** عنوان + وصف، محاذاة مركز، حد سفلي.
- **لا تقليم للنص:** العناوين والأوصاف تظهر كاملة.

تم تطبيق الإصلاحات أعلاه في الكود حسب هذا التشريح.
