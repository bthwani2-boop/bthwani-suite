# DSH Phase 3R Manual Design Work Order

Status: READY_FOR_MANUAL_DESIGN
Scope: Manual design work order only. No component edits, no visual implementation, no backend or API assumptions.

Global rules:
- Keep DSH finance language display-only wherever WLT owns semantics.
- Do not redesign runtime shells in this phase.
- Do not imply backend/runtime readiness from preview presence.
