# Execution Loops

Each loop is a closed cycle: diagnose → apply bounded correction → verify → evidence → re-diagnose.

## Loop 00 — Preflight Reality Lock

No code edits. Confirm current branch, dirty state, required docs, agent files, skills, and protected app-client rule.

## Loop 01 — Taxonomy, Noise, and Naming Guard

Goal: classify files and stop naming drift.

- Search for `closure-workspaces` in frontend.
- Classify each occurrence: docs/evidence allowed, frontend not final.
- Replace frontend names only when safe, without using vague `*Workspaces` plural names.
- Establish report for god-files and registered-only screens.
