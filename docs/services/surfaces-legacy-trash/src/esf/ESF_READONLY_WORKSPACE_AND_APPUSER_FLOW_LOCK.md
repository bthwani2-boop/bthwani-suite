## 1) شكل صفحة CONTROL PANEL النهائي

### ما يظهر فقط

1. **Header** — اسم الخدمة؛ الحالة (مفعّلة / موقوفة)؛ آخر تحديث.
2. **Coverage** — المناطق المتاحة؛ المدن المتاحة؛ هل الخدمة مفتوحة حاليًا.
3. **Light Stats** — الطلبات النشطة؛ المفتوحة؛ المغلقة / المكتملة إن وُجدت.
4. **Info Note** — الخدمة مجانية؛ التفاعل بين العملاء مباشرة؛ لا قبول/رفض/إسناد يدوي من لوحة التحكم.
5. **Simple Config** — تفعيل/إيقاف الخدمة؛ تحديد المناطق/المدن؛ إظهار/إخفاء استقبال الطلبات الجديدة؛ نص Banner يظهر داخل التطبيق.

### CTA في CONTROL PANEL

- لا CTA تشغيلي.
- فقط: **حفظ التغييرات** (عند تعديل الإعدادات)؛ **تحديث** عند الحاجة.

## 2) شكل App-Client النهائي

### المسارات التي تبقى (routes فقط)

- `EsfHome`
- `EsfRequestGet`
- `EsfMatchesInbox`
- `EsfMatchGet`

*(المسارات القديمة تبقى alias نحو الـ hub أو التفاصيل حسب التطبيق الحالي — بدون توسيع نطاق المسارات.)*

### ما يتحوّل إلى sheet / inline / confirm

| السلوك | الشكل |
|--------|--------|
| إنشاء طلب | Sheet (compose) |
| تحديث التوفر | Inline أو sheet |
| قائمة طلباتي | Sheet |
| بحث الطلبات | وضع بحث inline |
| إلغاء طلب | تأكيد (confirm) |
| قبول تطابق (match) | تأكيد أو action sheet |
| رفض تطابق | تأكيد أو action sheet |

### قواعد CTA

- **طالب الدم:** `اطلب دم الآن`
- **المتبرع:** `سأتبرع الآن`
- لا يوجد CTA رئيسي ثانٍ منافس في نفس السياق.

---

## 3) التدفقات النهائية

### طالب الدم

1. `EsfHome`
2. `اطلب دم الآن` → compose sheet
3. إرسال الطلب
4. الانتقال إلى `EsfRequestGet`

### المتبرع

1. `EsfHome`
2. رؤية الحالات المناسبة
3. تفاصيل سريعة أو كاملة ضمن نفس التدفق دون مسارات إضافية غير ضرورية

### إدارة الطلب

- من `EsfRequestGet` فقط: إلغاء / تعديل / تواصل عبر inline / sheet / confirm — **بدون route جديدة**.

## 5) ما لا يجب أن يوجد في CONTROL PANEL

- inbox  
- لوحة تفاصيل تشغيلية (detail panel)  
- assign / accept / reject / escalate  
- queue أو تشغيل يدوي  
- رسوم بيانية أو analytics ثقيلة  
- سجلات خام (raw logs)  
- تبويبات كثيرة  
- إعدادات متقدمة  
- أي CTA تشغيلي  

**مبدأ:** CONTROL PANEL = قراءة + إعدادات خفيفة؛ **App-Client** = السطح الفعلي للخدمة؛ **بدون** تدخل تشغيلي من الإدارة.
