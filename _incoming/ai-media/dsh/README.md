# DSH AI Real Media Replacement

ضع الصور المولدة بالذكاء الاصطناعي هنا بنفس الأسماء الموجودة في manifest:

- products
- stores
- banners

القواعد:
- PNG فقط
- نفس الأبعاد المطلوبة
- نفس اسم الملف بالضبط
- بدون نص داخل الصورة
- بدون شعارات أو علامات تجارية حقيقية
- بدون watermark
- لا روابط خارجية
- لا data:image

بعد وضع كل الصور، أعد تشغيل نفس السكربت وسيستبدل الصور الرسمية بعد التحقق.
