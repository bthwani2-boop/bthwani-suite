# Evidence — demo-service

Guidelines for including Evidence Packs and runtime proof for this service.

Place evidence zip files and screenshots under this folder, e.g.:

- `evidence_demo_001.zip` (contains SUMMARY.md, git_status.txt, typecheck.log, tests.log, screenshots/, logs/)
- `screens/` — before/after screenshots per screen and state
- `logs/` — runtime logs for smoke tests

Use the global template: `governance/EVIDENCE_PACK_TEMPLATE.md`
