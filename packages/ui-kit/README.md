# @bthwani/ui-kit — Premium V2

This package is the centralized UI authority package for BThwani.

## What this version strengthens
- stronger foundational tokens
- clearer semantic layering
- richer shared components
- more reusable screen shells
- better readiness for control-panel, webapp, website, and mobile apps

## Included layers
- foundation/tokens
- foundation/themes
- foundation/direction
- providers
- hooks
- primitives
- components
- patterns
- adapters
- docs

## Adoption intent
This package is meant to become the platform-level UI owner that screens depend on instead of recreating local visual systems.
