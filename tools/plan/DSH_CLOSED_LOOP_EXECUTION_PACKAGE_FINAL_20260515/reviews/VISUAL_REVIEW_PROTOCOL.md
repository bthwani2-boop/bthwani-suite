# Visual Review Protocol

The user reviews screen design after logic/file/flow closure.

For each screen/workspace, collect:

- screenshot,
- device/surface,
- language/direction,
- route/screen_id,
- expected primary CTA,
- before/after if changed,
- notes on clipping/overflow,
- notes on RTL,
- notes on screen grouping.

Review checks:

- visual hierarchy,
- RTL correctness,
- icon/text/chevron placement,
- CTA clarity,
- safe area,
- scroll/overflow,
- state coverage,
- no random visual drift,
- no unnecessary screen fragmentation,
- no god-screen overload,
- proper WLT/control-panel relation where relevant.
